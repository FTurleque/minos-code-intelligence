# ADR — Architecture documentation (index local)

Ce dossier contient le **template** et l'index des ADR pour la documentation d'architecture.

Les ADR sources du projet sont dans [`../../adr/`](../../adr/README.md).

---

## Utilisation du template

1. Copier [`template.md`](template.md) en `../../adr/NNNN-titre-court.md`.
2. Renseigner tous les champs.
3. Ajouter une ligne dans [`../../adr/README.md`](../../adr/README.md) et dans [`../arc42/09-decisions.md`](../arc42/09-decisions.md).
4. Ne jamais supprimer un ADR accepté — créer un nouvel ADR et marquer l'ancien « Remplacé ».
