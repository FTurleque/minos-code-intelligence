# Historique des validations transverses

Ce dossier conserve les référentiels de métriques et campagnes de validation qui ont traversé plusieurs jalons.

Ces documents peuvent contenir des seuils initiaux, des résultats intermédiaires ou des sections arrêtées avant M13. Ils servent à l'audit historique et ne remplacent pas les portes actuelles décrites dans `../milestones/`, `../../STATUS.md` et les PR/issues correspondantes.
