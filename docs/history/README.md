# Historique documentaire MINOS

Ce répertoire regroupe les documents qui expliquent **comment MINOS a été cadré, expérimenté et validé dans le temps**. Ils ne constituent pas la documentation opérationnelle courante.

Pour l'état actuel du produit, utiliser :

- [`../STATUS.md`](../STATUS.md) — état livré ;
- [`../ROADMAP.md`](../ROADMAP.md) — progression produit ;
- [`../user/`](../user/) — utilisation ;
- [`../developer/`](../developer/) — architecture et développement ;
- [`../adr/`](../adr/README.md) — décisions architecturales durables.

## Organisation

```text
history/
├── c0/
│   └── cadrage fonctionnel et architectural initial
├── validation/
│   └── référentiels et campagnes de validation historiques transverses
└── milestones/
    └── preuves et rapports M0 → M13
```

## Règle

Un document archivé peut contenir des formulations comme « à valider », « futur », un ancien nombre de tests, une ancienne stack ou un ancien SHA. Ces formulations sont conservées comme **état historique** et ne doivent pas être interprétées comme l'état actuel de MINOS.
