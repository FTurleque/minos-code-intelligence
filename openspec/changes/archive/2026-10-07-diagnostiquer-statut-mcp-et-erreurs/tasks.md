# Tasks

Conventions pour toutes les tâches :

- Format d'une tâche : `[constat | exigence]` suivi du travail et de sa validation observable.
  Les noms d'exigences sont ceux de `specs/surfaces-publiques/spec.md`.
- Toute commande Maven passe par le wrapper (`./mvnw`, ou `.\mvnw.cmd` sous Windows), avec
  `-B -ntp`, et tout `-pl` s'accompagne de `-am`. Avec `-Dtest=…`, ajouter
  `-Dsurefire.failIfNoSpecifiedTests=false` (les modules amont n'ont pas ce test). Ne pas écrire de
  journal de build dans le `target/` racine (supprimé par `clean`).
- Les tests rouges de la tranche 1 sont écrits contre les API existantes (ils compilent avant le
  correctif) et placés sous
  `@EnabledIfSystemProperty(named = "minos.audit.repro", matches = "true")` : sautés par défaut
  pour ne pas rendre `verify` rouge, rejoués rouges par `-Dminos.audit.repro=true`. Le correctif
  retire la condition dans la tâche qui les fait passer.
- Gates littéraux à rejouer pour toute tâche qui touche `MinosMcpTools.java` ou
  `MinosApplicationMcpBackend.java` : `python scripts/remediation/check-p0-p2.py` (exige
  `error: MINOS tool execution failed`, interdit `effective.getMessage()` dans `MinosMcpTools.java`),
  `python scripts/remediation/check-post-mne.py` (exige `MAX_RESULT_BYTES`,
  `MCP_RESULT_BUDGET_EXCEEDED`, `exceedsUtf8Budget`, `renderProgramGraph`),
  `python scripts/quality/check-hosted-control-plane-consistency.py` (exige dans le backend
  `System.getenv("MINOS_TEAM_TOKEN")`, `hosted().tenant(hostedToken())`,
  `hosted().audit(hostedToken(), limit)`, `MINOS team mode is disabled`, et interdit `bearerToken`
  dans `MinosMcpTools.java`) et `python scripts/quality/check-runtime-dynamic-consistency.py`.
- Scopes JaCoCo de `scripts/quality/check-jacoco.py` concernés : `mcp-mapping`
  (`com/minos/mcp/`), `m19-m20-mcp-catalogue` (`MinosMcpTools`), `public-api` (`com/minos/api/`),
  `project-resolution` (`ProjectResolver`, y compris `ResolutionException`). Rejoués en 9.1.
  Aucun scope JaCoCo ne cible `com/minos/cli/` pour ces commandes : les tests CLI sont la barrière.
- Le catalogue MCP et les schémas ne changent pas : `python scripts/docs/product-facts.py --check`
  n'est rejoué qu'en 9.1 par précaution (si, contre toute attente, le catalogue change, le
  régénérer d'abord) ; `scripts/quality/check-tools-manifest.py` n'est pas concerné.
