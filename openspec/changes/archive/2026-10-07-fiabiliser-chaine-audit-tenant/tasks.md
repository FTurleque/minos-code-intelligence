# Tasks

Conventions pour toutes les tâches :

- Format d'une tâche : `[constat | exigence]` suivi du travail et de sa validation observable.
  Les noms d'exigences sont ceux de `specs/controle-tenant-heberge/spec.md`.
- Toute commande Maven passe par le wrapper (`./mvnw`, ou `.\mvnw.cmd` sous Windows), avec
  `-B -ntp`, et tout `-pl` s'accompagne de `-am`. Avec `-Dtest=…`, ajouter
  `-Dsurefire.failIfNoSpecifiedTests=false` (les modules amont n'ont pas ce test). Ne pas écrire de
  journal de build dans le `target/` racine (supprimé par `clean`).
- Les tests de reproduction rouges sont rendus actifs par `-Dminos.audit.repro=true`
  (`@EnabledIfSystemProperty(named = "minos.audit.repro", matches = "true")`). Un test rouge est
  sauté par défaut pour ne pas rendre `verify` rouge ; il perd cette condition dans la tâche qui
  le fait passer.
- Gates littéraux à rejouer pour toute tâche qui touche `com.minos.hosted` ou le magasin
  hébergé : `python scripts/quality/check-hosted-control-plane-consistency.py` et
  `python scripts/remediation/check-p0-p2.py` (chaînes affirmées : `authorizeMutation`,
  `HostedAuditEvent.Outcome.DENIED`, `hosted permission denied`, `auditChain.verify(state)`,
  `hosted audit event authentication failed`, `HmacSHA256`, `DEFAULT_MAX_TENANT_BYTES`, et les
  méthodes de test `rejectsPersistedAuditEventWithInvalidHmac`,
  `authenticatesAndEnforcesRbacWhileAuditingDeniedMutations`,
  `rotatesEncryptionAndSigningKeyAndInvalidatesOldToken`). Ne supprimer ni renommer aucune de ces
  chaînes.
- Scope JaCoCo concerné : `m27-team-hosted-control-plane` de `scripts/quality/check-jacoco.py`
  (rejoué en 8.2).
