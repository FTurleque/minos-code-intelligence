# Tasks

Conventions. Chaque tâche écrit d'abord le test rouge, puis le correctif, dans la même tâche.
Les commandes Maven passent par le wrapper et tout `-pl` s'accompagne de `-am` ;
`-Dsurefire.failIfNoSpecifiedTests=false` évite l'échec des modules amont sans test correspondant.
Les journaux de build ne s'écrivent pas dans le `target/` racine, que `clean` supprime.
Le test de reproduction existant
`minos-storage-postgresql/src/test/java/com/minos/storage/postgresql/AuditReproPostgresJdbcUrlPolicyTest.java`
(MINOS-AUD-B07, rouge vérifié) est rendu actif par `-Dminos.audit.repro=true` et sauté par défaut
(`@EnabledIfSystemProperty(named = "minos.audit.repro", matches = "true")`). Constats : MINOS-AUD-B07
et MINOS-AUD-B08 (P2), MINOS-AUD-B13 et MINOS-AUD-B09 (P3). Aucune E/S brute n'est ajoutée hors des
primitives (`BoundedProperties` et `DurableAtomicFile` en sont) : `check-private-io.py` doit rester
vert.
