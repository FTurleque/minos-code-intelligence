# Tasks

Conventions. Chaque tâche écrit d'abord le test rouge, puis le correctif, dans la même tâche.
Les commandes Maven passent par le wrapper et tout `-pl` s'accompagne de `-am` ;
`-Dsurefire.failIfNoSpecifiedTests=false` évite l'échec des modules amont sans test correspondant.
Les journaux de build ne s'écrivent pas dans le `target/` racine, que `clean` supprime. Le scope
JaCoCo `m24-polyglot-provider-platform` est rouge hors régression sous Windows : comparer avec
`develop` avant d'investiguer. Constats : MINOS-AUD-F01 (P1), MINOS-AUD-F04, MINOS-AUD-F02 (P2).
F03 n'a aucune tâche bloquante (voir la fin du fichier).
