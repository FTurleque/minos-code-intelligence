# Tasks

Le constat vient du superviseur de code, pas de l'audit : les tâches ne portent donc pas d'identifiant `AUD-…`. Remaniement à comportement constant : la caractérisation tient lieu de rouge (design D1), sauf pour les coutures de test ajoutées, qui ont un vrai rouge (le test ne compile pas ou échoue tant que la couture n'existe pas). Tout `-pl` s'accompagne de `-am`. **Deux PR, une par module** (sections 2 et 3), après la fusion préalable des deux branches `refactor/*` du superviseur dans `develop` (tâche 1.1). Aucun appel brut n'est ajouté : chaque entrée de `private-io-allowlist.json` change de clé de fichier, jamais de total. Sur le poste Windows, JDK 25 par `JAVA_HOME` explicite ; citer les arguments `-D`.
