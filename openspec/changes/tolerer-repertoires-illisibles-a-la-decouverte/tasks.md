Convention de traçabilité : chaque tâche cite `[MINOS-AUD-XNN / « nom exact de l'exigence »]` (exigences de `specs/decouverte-et-negociation/spec.md`) puis sa validation observable. Tout `-pl` est accompagné de `-am` ; `-Dsurefire.failIfNoSpecifiedTests=false` est nécessaire avec `-am` pour que `-Dtest` n'échoue pas dans les modules amont.
