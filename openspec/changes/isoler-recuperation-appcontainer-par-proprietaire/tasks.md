# Tasks

Convention de traçabilité : chaque tâche cite `[MINOS-AUD-XNN / « nom exact de l'exigence »]` (exigences de `specs/confinement-code-non-fiable/spec.md`) puis sa validation observable. Tout `-pl` est accompagné de `-am` ; `-Dsurefire.failIfNoSpecifiedTests=false` est nécessaire avec `-am` pour que `-Dtest` n'échoue pas dans les modules amont. Les tests rouges d'audit portent `@EnabledIfSystemProperty(named = "minos.audit.repro", matches = "true")` (convention de `AuditReproHostedDenialChainTest`) jusqu'au correctif, qui retire cette condition. Ne pas écrire de journaux de build dans le `target/` racine.
