# Tasks

Ordre dans chaque section : rouge, correction, preuve. Les tests vivent dans le module de la classe qu'ils couvrent (SonarCloud juge le nouveau code module par module, seuil 80 %, rapports Linux et Windows). Une ligne de `ENGINE_TYPES_NAMED_BY_SURFACE` disparaît dans la tâche qui retire son dernier usage (D6). Remplacer un nom par `var` ou par un chaînage d'accesseurs n'est pas un retrait. Placement des nouveaux types fixé par le design (« Direction des dépendances ») : tout type rendu par un service de `com.minos.application` vit dans `com.minos.application`, sinon A8 refuse le cycle. Toute commande `-Dtest` accompagnée de `-am` porte `"-Dsurefire.failIfNoSpecifiedTests=false"` (les modules amont n'ont pas ces tests). Chaque tâche de code rejoue `python scripts/architecture/check-module-boundaries.py` (A8, A11, A14, A15). Toutes les tâches portent **AUD-ARC-01**.
